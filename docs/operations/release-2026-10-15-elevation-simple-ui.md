# コースの高低差カードの簡素化

ユーザーが承認したSuperdesignモック v5を大会共通の高低図へ実装。獲得標高と同じ距離区分の平均との差を左右に配置し、「フルマラソン平均より」「ハーフマラソン平均より」と符号付きメートル値で表示する。最低・最高標高、標高差、比較対象数と平均はⓘの詳細にまとめた。長い獲得標高の説明と地形・橋・トンネルの注記を削除し、国土地理院への出典リンクを残した。

グラフのタップ・ドラッグ・キーボード操作と地図の地点選択、標高欠測区間の分断、経路確認中の注意は維持する。詳細は閉じるボタン、Escape、外側クリックで閉じられる。算出不能な獲得標高や比較値は引き続き表示しない。
