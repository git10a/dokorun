# コースの雰囲気画像の制作

2026-10-14：周辺写真を自動的に各区間へ割り当てる方式から、掲載ルート上の景観を確認して参考イメージを制作する方式へ変更する。

## 現地確認から制作まで

1. 掲載GPX上の代表地点を選ぶ。公園名だけで写真検索して区間に割り当てない。
2. Googleマップのストリートビューや現地写真を実際に開く。撮影地点・方向・撮影日を確認し、路面、幅、勾配、木々、周囲の建物を記録する。
3. 画像生成はその観察記録に基づいて行う。確認していない山、川、橋、標識などを追加しない。舗装路とトレイルを取り違えない。
4. 生成画像と参照景観を見比べる。雰囲気の一致は、地点・経路・現在の通行状況の正確さを保証しない。
5. ファイルとともに、対象slug、参照地点・URL・撮影日、観察記録、生成日、プロンプト、確認結果を保存する。
6. 掲載する場合は画像のそばに「AI生成の参考イメージ」と表示する。実写の写真クレジットを流用せず、正確な地点の実写に見える距離バッジを付けない。

代々木公園・皇居・駒沢公園に各2場面をローカル実装した。皇居は反時計回りの視点（東側は北向き、西側は南向き）に統一。掲載台帳は `src/lib/course-atmosphere.ts`、画像は `public/course-atmosphere/`。制作記録と元PNGは `output/course-atmosphere/` に保存する。本番への公開は未実施。

同日、神宮外苑・豊洲ぐるり公園・水元公園・長居公園・大濠公園にも各2場面を追加し、計8コース16枚とした。第2組の参照パノラマ・撮影時期・観察記録・生成プロンプトは `output/course-atmosphere/batch-2-sources-and-prompts.json` に保存。長居公園の南西側と大濠公園の北西側では、Googleマップがルートから離れた車道写真を表示したため採用せず、ルート沿いの別地点へ切り替えた。

生成画像は各画像の直下と代替テキストで明記し、参考地点のGoogleマップへリンクする。実写用のヒーロー画像や写真クレジットには流用しない。参考写真の撮影時期が古いため、現在の設備・路面表示を保証するものとして扱わない。

## 既存データの掲載判定

元の候補データは調査用に保持する。`preparePublicCourseGuide` は、`src/lib/course-photo-reviews.json` にコース・チェックポイント・出典URL・表示画像URLの組が登録されている実写だけを返す。ファイル名の禁止語や検索スコアは掲載の根拠にしない。生成スクリプトからレビュー台帳を更新しない。

2026-10-14に、鎌倉一周・手賀沼一周・山手線一周の地名付き画像17枚を実画像で確認した。これは掲載地点に対応する被写体の確認であり、現在の現地状態やGPX全区間の検証ではない。

確認できた画像がないページでは、写真セクションと機械的な代替カードを表示しない。地図・高低図・アクセス・GPXは維持する。生成画像を掲載する際は、実写レビュー台帳とは別に参照記録と掲載表記を管理する。
