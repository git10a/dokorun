# ランニングスポットの標高・景色画像

2026-10-16時点。対象は公開中の全251スポット。**全件完了ではなく、本番未反映です。**

## 実装済み

- 大会ページと同じ `RaceElevationChart` を使用。タップ・ドラッグ・矢印キーで選んだ距離に対応する地点を地図上に表示する。
- 周回のスタート変更では距離・標高・座標を一緒に並べ替え、逆方向にも対応。スタート変更時には前の選択を消す。
- 画像の「コース上で見る」から地図とグラフの同じ地点を選択。画像の距離も選択したスタートに合わせる。
- ガイド付き250ページと、ガイドのないみどり湖ページの両方に対応。
- 読み込み中にもグラフの高さを確保し、画像へのリンク位置が大きくずれるのを抑える。
- 既存16枚を保持。3担当が全スポットの実景確認と画像生成を継続している。最新の登録枚数・未完了件数は `data/spot-experience/coverage.json` に記録する。

## 標高・経路の状況

全251スポットに元の標高サンプルがあり、距離と座標の整合をテスト済み。これは全経路が現地と一致することを確認した意味ではない。

実景との照合で3件の経路不一致を確認し、次の参考コースへ修正した。全251件の表示用標高データがある。

- **青葉の森公園**：千葉テレビ付近の公道から、公式の2kmジョギングコースを参考に園内の約1,989m周回へ修正。西口側を起点とし、現行の工事エリアを避ける。
- **21世紀の森と広場**：松戸運動公園近隣の住宅街から、光と風の広場の約823m参考周回へ修正。公式に記載された広場1周950mとは異なることを明記する。
- **荒川河川敷**：豊島周辺の街路から、新荒川大橋付近を起点に上流へ5km進んで戻る10km参考往復コースへ修正。照合済みの東京・赤羽ハーフの経路前半を利用し、大会公認コースとの同一性は表示しない。

公式資料、OSM経路、GSI標高の参照記録は `data/spot-experience/route-corrections/`、修正前の不一致と修正履歴は `route-reviews.json` に保存。3件の本番DB修正・復元SQLは元の値との一致を条件とし、実行直前に本番の状態を照合する。現時点ではローカル公開カタログのみに適用済み。

駅検索データも修正した起点から再計算。1436件の既存駅URL・590件の路線URLを保持し、13件の駅ページを追加。経路訂正で近隣コースが減っても、既存駅ページは電車で行けるコースが1件以上あれば維持する。

## 画像と記録

新規画像はすべて **内蔵 image_gen** で1枚ずつ生成。Google Mapsのパノラマを実際に開き、撮影地点・方向・撮影時期・路面・周囲の配置を確認した観察文を使用。API/CLIによる画像生成は使っていない。

- 最終画像：`public/course-atmosphere/`
- 新規掲載台帳：`src/lib/spot-atmosphere-catalog.json`
- 参照地点・観察・最終プロンプト・目視レビュー：`data/spot-experience/*-sources-and-prompts.json` と `data/spot-experience/batch-*/sources-and-prompts.json`
- 既存画像の記録：`data/spot-experience/existing-references/`

AI画像であることをセクション説明・各画像の直下・代替テキストに表示する。参照した景色の再構成であり、現在の路面状態や個々の建物・木・石の正確な再現を保証しない。

## 全件作業の継続

`npx tsx scripts/audit-spot-experience.ts` で `data/spot-experience/coverage.json` を更新。`--require-complete` は全251件の利用可能な標高と各2枚の登録画像がそろわなければ失敗する。候補地点のリンクだけでは画像確認済みにしない。
